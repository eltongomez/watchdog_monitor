📥 Instalação

Método 1: Download Manual

# 1. Baixe e descompacte o WatchdogMonitor-v3.2.0.zip
# 2. Mova para Applications
mv WatchdogMonitor.app ~/Applications/

# 3. Abra o app
open ~/Applications/WatchdogMonitor.app

Método 2: Via Git

git clone https://github.com/eltongomez/watchdog_monitor.git
cd watchdog_monitor
./install.sh
