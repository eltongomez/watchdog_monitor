🚨 Problemas que o Watchdog Resolve

Se você enfrenta estes problemas no seu Mac, o Watchdog Monitor é a solução definitiva:

💥

Kernel Panics Inexplicáveis

Crashes repentinos com mensagem "watchdog timeout: no checkins from watchdogd" que reiniciam o Mac sem aviso.

🔥

SMC Travado

System Management Controller para de responder, causando freezes, superaquecimento e crashes do sistema.

🐌

Memória Esgotada

Sistema lento devido à falta de RAM, com risco de travamento ao abrir aplicações pesadas.

⚠️

Carga Excessiva

CPU sobrecarregada com processos pesados que tornam o sistema instável e irresponsivo.

📉

Perda de Trabalho

Reinicializações forçadas causando perda de documentos não salvos e projetos abertos.

🔄

Crashes Recorrentes

Problemas que se repetem diariamente, prejudicando produtividade e confiabilidade do Mac.

✨ Features Revolucionárias v3.2

Sistema inteligente com prevenção proativa e recuperação automática

🎚️

Recovery Profiles

Conservative (Seguro), Balanced (Recomendado) ou Aggressive (Performance). Escolha o perfil ideal para seu uso.

🛡️

Anti-Crash Mode

4 níveis de proteção: Off, Light, Moderate, Aggressive. Keep-alive inteligente previne idle problemático.

⚡

Preemptive Recovery

Detecta tendências e age ANTES dos problemas. Machine learning básico analisa 100 últimas leituras.

🟢

Menu Bar Nativo

App Swift com status visual em tempo real: Verde (OK), Amarelo (Alerta), Vermelho (Ação).

🔄

Recovery Automático

Limpa cache, sincroniza disco, reduz prioridade de processos. Tudo automaticamente antes do crash.

📊

Monitoramento 24/7

6 métricas vitais: SMC, Temperatura, I/O, Load, Memória, RPM dos Coolers. Checks a cada 15s.

📥 Instalação Rápida

Escolha o método que preferir. Instalação completa em menos de 2 minutos.

🚀 Método Recomendado

Clone o repositório e execute o instalador automático:

git clone https://github.com/eltongomez/watchdog_monitor.git
cd watchdog_monitor
./install.sh

O instalador configura tudo automaticamente: app, daemon, sudo e LaunchAgent.

⬇️ Download Manual

Baixe o .zip, descompacte e mova para Applications:

# Após baixar WatchdogMonitor-v3.2.0.zip
unzip WatchdogMonitor-v3.2.0.zip
mv WatchdogMonitor.app ~/Applications/
open ~/Applications/WatchdogMonitor.app

Configure sudo manualmente seguindo o guia de instalação.
